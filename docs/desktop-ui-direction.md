# KOAN Plus デスクトップUI再構成案

2026-09-05。構造変更の実装前に同意を得るための提案。モバイル・レスポンシブの変更は対象外。

## 目的

利用者が「次の授業はどこか」「何をいつまでに終えるか」「選んだ授業で何をするか」を迷わず判断できるようにする。狭い右カラムへ詳細を詰める構成を改め、ページごとに必要な情報へ幅を配分する。

## 合意済みの改善として実装した内容

- 初回ページは機能説明の1文と任意のログイン設定までの手順を明示。宣伝的な大見出しは利用者の指摘を受け削除。
- 課題とアンケートを締切順で混在させ、今日・今週・それ以降・期限未設定に整理。
- 取得済みの空データと未取得・更新中・未確認を区別。空の領域には取得の入口を置き、保存済みの内容がある領域の更新状況はヘッダーへ集約。
- 授業・締切の行の高さを内容に合わせ、教室や変更情報の重なりを解消。
- 掲示の大学による重要指定と拡張機能の確認候補を区別。候補の理由、検索結果件数、条件クリア、ホームから掲示一覧への入口を追加。
- CLE課題リンクの移動先を説明し、カレンダーの前後月の日付を読みやすく変更。

## 同意後に作り変える範囲

| 場所 | どう変えるか | 利用者への効果 |
| --- | --- | --- |
| ホーム | 常設の右カラムをなくす。主領域の上段を「選択日の予定」と「次にやること」の2列にし、連絡・掲示を下段へ。日付移動は予定の上、月カレンダーは日付ボタンから開く。 | 授業と締切を同じ視線の高さで確認でき、同じ締切の重複表示を減らせる。 |
| 授業 | 時間割から科目を選ぶと、主領域を使う授業詳細へ移る。上部に科目名・教室・直近の変更と主要操作。課題・連絡・資料・変更履歴はタブで切り替える。 | 長いタイトルや資料一覧に幅を使える。細い欄と複数の内側スクロールをなくせる。 |
| 設定 | 常設の説明用サイドバーをなくし、中央の1列へ。ログイン・二段階認証・データ管理を見出しで分け、必要な説明は該当操作のそばへ。長い補足は展開式にする。 | 操作と説明を往復せず、その場で判断できる。 |
| 左ナビ | ラベンダーの丸い選択背景と短い縦線の組み合わせをやめる。選択中は薄い中立色の背景と文字の太さで示し、フォーカス表示は別に保持する。 | 現在地を明確にしつつ装飾の重複を減らす。 |

## 操作の約束

- ホームは選択日を1か所で管理し、日付を変えると予定が切り替わる。締切は横断一覧を維持し、選択日の締切位置へ進めるようにする。
- 月カレンダーを閉じても選択日は維持。「今日に戻る」を用意し、キーボードでも操作できるようにする。
- 授業詳細から時間割へ戻ると、期間・選択科目・スクロール位置を維持する。詳細上部から別の科目にも直接切り替えられるようにする。
- 授業詳細は初期表示を課題にし、連絡や変更の未確認件数をタブにも示す。直近の休講・教室変更はタブを開かなくても上部で確認できるようにする。
- 設定の説明を折りたたんでも、保存結果・入力エラー・削除の確認は常に操作のそばに表示する。
- 新しいカードやバッジを増やして飾らず、見出し・余白・罫線・文字の強弱で階層を作る。ロゴと既存の基調は生かす。

## トレードオフと検証

月全体を見る操作と授業内の情報切り替えには1操作増える。その代わり、通常利用時の情報密度とスクロールの競合を減らす。日付の選択保持、科目の直接切り替え、重要な変更の常時表示で補う。

実装後は実測する。次の授業の教室と最も近い締切を短時間で見つけられるか、課題から資料へ迷わず移れるか、時間割へ戻って元の位置から続けられるかを検証する。現時点でUX向上率や操作時間の改善を実証したという意味ではない。

この文書の構造変更は、利用者の同意を得るまで実装しない。

## 今回の検証範囲

型チェック・ビルド・109件の単体テスト・27件の画面テストを確認。合成データのローカル画面で初回案内、締切順、授業の重なり、検索・解除、未取得・取得できない状態、ライト・ダークを確認した。大学の実サーバーへの認証・取得は今回の検証対象外。実環境では拡張機能を再読み込みし、ホームの更新後に課題・アンケートの順序と、授業名・教室・変更の表示を確認する。
